Every stage lists its real route, components, request payload and status enum.

Shortlist Request loop

ShortlistRequests:Approve / Reject

HR sends a request; an approver decides. CreateShortlistRequest { jobApplicationId }. On approve the application becomes Shortlisted; on reject it can be resent or the application rejected.

F

Assessor Scoring

Built · Assessor /recruitment/assessments/[jobPostingId]/[interviewId]

Each assessor sees only the interviews assigned to them (AssessorInterviewListItem), filtered by their own submission status. They open the interview and score every weighted construct — ConstructScore { constructName, score } — then submit.

Pending queue

AssessorSubmissionStatus.Pending (0) — not yet scored.

Completed

AssessorSubmissionStatus.Completed (1) — scores submitted.

Permissions

AssessorInterviews:Read · AssessorInterviews:Submit

offer accepted → hire
